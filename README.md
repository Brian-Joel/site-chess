# Sobre o projeto
O Xeque-mate é uma plataforma web para ensinar e espalhar a paixão pelo xadrez de forma visual e interativa. No site, o usuário aprende a teoria, testa o conhecimento em quizzes e vê sua própria evolução através de gráficos.

# Funcionalidades
- Cadastro e login de usuários
- quiz interativo de xadrez
- Visualização de estatísticas de quiz
- Dashboards com gráficos interativos

# Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- MySQL
- Node.js
- API Chart.js

# Banco de dados
O sistema utiliza um banco de dados relacional para armazenar:

- Usuários
- Estatísticas

# Objetivo
Democratizar o ensino do xadrez e espalhar a apreciação pelo jogo, transformando tabuleiros em ferramentas de aprendizado acessíveis para todos. O foco do sistema é guiar o usuário para as regras básicas, conectando a teoria à prática de forma leve e interativa. Mais do que apenas ensinar a jogar, o projeto visa introduzir a cultura do xadrez, estimulando o raciocínio lógico e o gosto pelo esporte.
